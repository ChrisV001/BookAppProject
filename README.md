# BookAppProject

BookAppProject is an Android application built with *Kotlin* that allows users to register, manage book categories, and view relevant book information. It uses *Firebase* services (Authentication and Realtime Database) for user management and data storage.

## Table of Contents
- [Overview](#overview)
- [Installation & Setup](#installation--setup)
- [Additional Resources](#additional-resources)
- [Usage on Mobile Devices](#usage-on-mobile-devices)

## Overview
- *Language*: Kotlin for Android.
- *Firebase Authentication*: Creates user accounts, validates user input, and logs them in.
- *Firebase Realtime Database*: Stores and retrieves categories, user details.
- *UI Components*: Basic Android UI (e.g., TextView, ImageButton, AlertDialog, Toast, etc.).
